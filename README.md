# Application d'archivage de documents
Un document déposé aujourd'hui devra être lu et vérifiée dans 10 ans avec des algorithmes qui auront évoluer entre temps.

## Scénario précis
Un service d'archivage de pièces justificative dans une compagnie d'assurance (contrat, déclaration de sinistre, ...)

### Les fonctions minimales :
- Déposer un document : il est chiffré et signé.
- Consulter un document : on vérifie la signature, puis un déchiffre.
- migrer les documents existant vers de nouveaux algorithmes.
- Inventorier : savoir quels documents utilisent quels algorithmes.
